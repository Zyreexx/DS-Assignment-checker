LeetCode Assignment Checker by Pushp (Chrome / Edge)
============================================

Install locally
1. Unzip leetcode-assignment-extension.zip.
2. In Chrome, open chrome://extensions. In Edge, open edge://extensions.
3. Turn on Developer mode.
4. Click Load unpacked and select the unzipped leetcode-assignment-extension folder.
5. Sign in to leetcode.com, refresh the page, and click the extension icon.
6. Choose Check progress. Unsolved problems appear under Remaining problems in
   Array, Stack, Linked List, Tree, Graph order, each with its LeetCode link and
   YouTube solution link.
